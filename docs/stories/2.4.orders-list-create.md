## Story
**As a** usuário autorizado,
**I want** listar ordens de serviço e abrir novas,
**so that** o processo de compras seja iniciado com todos os dados necessários.

## Acceptance Criteria
1. Listagem com campos: código OS, status (badge), secretaria, criador, data, melhor oferta, qtd propostas
2. Formulário com todos os 13 campos (a–m) funcionais
3. Pesquisa inteligente de itens com autocomplete + imagem + valor de referência
