## Story
**As a** gestor aprovador,
**I want** confirmar ações críticas com código 2FA,
**so that** aprovações de OS e empenhos tenham dupla confirmação de identidade.

## Acceptance Criteria
1. `POST /api/auth/2fa/request` gera OTP de 6 dígitos e envia por e-mail
2. OTP expira em 5 minutos após geração
3. OTP só pode ser usado uma vez (marcado como `used = true`)
4. `POST /api/auth/2fa/validate` retorna `{ valid: true }` para OTP correto e não expirado
5. `POST /api/auth/2fa/validate` retorna `{ valid: false }` para OTP incorreto ou expirado
6. Componente `<TwoFactorModal>` reutilizável exibido antes de aprovar OS e enviar empenho
7. OTP inválido 3 vezes consecutivas bloqueia a ação por 5 minutos

## Tasks / Subtasks
- [ ] Instalar dependências (AC: 1)
  - [ ] `nodemailer` (ou `@sendgrid/mail`) para envio de e-mail
  - [ ] `otplib` ou gerar OTP manualmente com `crypto.randomInt(100000, 999999)`
- [ ] `POST /api/auth/2fa/request` (AC: 1, 2)
  - [ ] `src/app/api/auth/2fa/request/route.ts`
  - [ ] Gerar OTP (6 dígitos), salvar hash (bcrypt) em `TwoFactorRequest` com expiresAt = now + 5min
  - [ ] Enviar OTP por e-mail para o usuário autenticado
  - [ ] Retornar `{ otpToken: string, expiresIn: 300 }` (otpToken é o ID do TwoFactorRequest)
- [ ] `POST /api/auth/2fa/validate` (AC: 3, 4, 5, 7)
  - [ ] `src/app/api/auth/2fa/validate/route.ts`
  - [ ] Buscar TwoFactorRequest por otpToken
  - [ ] Verificar: não expirado + `used = false` + bcrypt.compare(code, otpHash)
  - [ ] Se válido: marcar `used = true`, retornar `{ valid: true }`
  - [ ] Se inválido: incrementar contador de falhas, retornar `{ valid: false }`
  - [ ] 3 falhas consecutivas: bloquear por 5min (salvar `blockedUntil` no TwoFactorRequest)
- [ ] Implementar `src/services/auth.service.ts` — métodos 2FA (AC: 1, 4)
  - [ ] `requestTwoFactor(action)` e `validateTwoFactor(otpToken, code)` via axios
- [ ] Componente `<TwoFactorModal>` (AC: 6)
  - [ ] `src/components/auth/TwoFactorModal.tsx`
  - [ ] Props: `isOpen`, `action`, `onSuccess(otpToken, code)`, `onCancel`
  - [ ] UI: input de 6 dígitos (autofocus), botão "Confirmar", botão "Reenviar código" (cooldown 60s)
  - [ ] Mensagem de erro se código inválido
  - [ ] Exportar como componente reutilizável
- [ ] Testes (AC: 2, 3, 5, 7)
  - [ ] OTP expirado retorna `{ valid: false }`
  - [ ] OTP já usado retorna `{ valid: false }`
  - [ ] 3 falhas → bloqueio por 5min
