## Story
**As a** equipe de desenvolvimento da Synkra,
**I want** configurar o pipeline de build EAS e submeter o app ao TestFlight,
**so that** o app iOS esteja disponível para a Prova de Conceito (PoC) com a Prefeitura de Araçuaí.

## Acceptance Criteria
1. `mobile/eas.json` configurado com profiles: `development`, `preview` e `production`
2. `mobile/app.json` configurado com `bundleIdentifier: "br.gov.aracuai.saasbi"`, nome "BI Araçuaí" e versão "1.0.0"
3. Comando `eas build --platform ios --profile preview` executa sem erros e gera IPA válido
4. Build de preview submetido ao TestFlight com sucesso (demonstrável via link ou screenshot)
5. `mobile/README.md` documenta: pré-requisitos, configuração de variáveis de ambiente, comandos de build e instruções de acesso ao TestFlight
6. `npx expo-doctor` não reporta erros críticos de configuração
7. Critério REQ-49 PoC: "App iOS disponível na App Store ou demonstrado em TestFlight"

## Dev Notes
**Pré-requisitos obrigatórios (fora do escopo desta story — garantir antes de iniciar):**
- Apple Developer Account ativa (USD 99/ano)
- Bundle ID `br.gov.aracuai.saasbi` registrado em developer.apple.com
- Certificado de distribuição iOS e provisioning profile configurados no EAS
- App criado no App Store Connect

**Estrutura do `eas.json`:**
```json
{
  "cli": {
    "version": ">=10.0.0"
  },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal"
    },
    "preview": {
      "distribution": "internal",
      "ios": {
        "simulator": false
      }
    },
    "production": {
      "distribution": "store",
      "ios": {
        "buildConfiguration": "Release"
      }
    }
  },
  "submit": {
    "production": {
      "ios": {
        "appleId": "dev@prefeitura-aracuai.mg.gov.br",
        "ascAppId": "PLACEHOLDER_APP_ID",
        "appleTeamId": "PLACEHOLDER_TEAM_ID"
      }
    }
  }
}
```

**Checklist App Store (documentar no README):**
- [ ] Apple Developer Account USD 99/ano
- [ ] Bundle ID registrado: `br.gov.aracuai.saasbi`
- [ ] Screenshots obrigatórias (iPhone 6.7" e 5.5")
- [ ] Política de privacidade (URL pública obrigatória)
- [ ] Descrição do app em português
- [ ] Categoria: Business ou Productivity

**Lead time:** App Store Review leva 2–7 dias úteis. TestFlight (internal testing) fica disponível imediatamente após o build ser processado pela Apple (~30 min).

**Nota sobre secrets:** Nunca commitar `EXPO_PUBLIC_API_URL` com valor real. Usar `eas secret:create --scope project --name EXPO_PUBLIC_API_URL --value <url>` para configurar no servidor EAS.
