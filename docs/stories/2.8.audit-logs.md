## Story
**As a** auditor ou órgão de controle,
**I want** visualizar todos os logs de ação do sistema,
**so that** qualquer operação seja rastreável e os registros sejam imutáveis.

## Acceptance Criteria
1. Todas as ações registradas automaticamente
2. Foto do usuário visível em cada log
3. Filtro por status funcional
4. `DELETE /api/audit/logs/:id` retorna 403
5. IP registrado em cada ação

## Tasks / Subtasks
- [x] `src/services/audit.service.ts` — listAuditLogs com filtros
- [x] `GET /api/audit/logs` com filtros: userId, status, from, to, paginação
- [x] `DELETE /api/audit/logs/:id` → 403 sempre
- [x] `PATCH /api/audit/logs/:id` → 403 sempre
- [x] Middleware de auditoria automática (registra todas as requisições autenticadas)
- [x] Página `/audit/logs` — tabela: foto, nome, ação, URL, IP, status badge, data/hora
- [x] Filtros por status (SUCCESS/FAILED/SUSPICIOUS), período, usuário
- [x] Testes: DELETE retorna 403, PATCH retorna 403, listagem com filtros
