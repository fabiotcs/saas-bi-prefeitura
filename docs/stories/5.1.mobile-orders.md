## Story
**As a** servidor municipal que usa o app iOS em campo,
**I want** visualizar e filtrar a lista de ordens de serviço no meu iPhone,
**so that** eu possa acompanhar o status dos pedidos sem precisar acessar o computador.

## Acceptance Criteria
1. Tela `mobile/src/app/(app)/orders.tsx` existe e renderiza no simulador iOS sem erros
2. Listagem consome `GET /api/orders` via `mobileApi` e exibe os pedidos retornados
3. Cada card exibe: código do pedido, nome/descrição, status (badge colorido), data de criação e secretaria responsável
4. Filtro por status funcional: OPEN, IN_QUOTATION, APPROVED, IN_PROGRESS, COMPLETED, CANCELLED
5. Pull-to-refresh atualiza a lista sem recarregar o app
6. Toque em um card navega para a tela de detalhes do pedido (`/orders/[id]`)
7. Estado de loading exibido durante a requisição (ActivityIndicator ou skeleton)
8. Estado vazio exibido quando não há pedidos para o filtro selecionado
9. Mensagem de erro exibida quando a requisição falha, com botão de retry
10. Critério REQ-49 PoC: "Listagem de pedidos funcional no app"

## Dev Notes
**Dependência:** Story 5.4 (scaffold) deve estar concluída. `mobileApi` e estrutura de pastas já existem.

**Endpoint backend:** `GET /api/orders` — já implementado no EPIC-2. Verificar se aceita query param `?status=` para filtragem server-side. Se não aceitar, implementar filtragem client-side no serviço.

**Navegação:** Usar `expo-router` file-based. O arquivo `orders/[id].tsx` cria automaticamente a rota `/orders/:id`. Navegar com:
```typescript
import { router } from 'expo-router'
router.push(`/orders/${order.id}`)
```

**Interface MobileOrder:**
```typescript
export interface MobileOrder {
  id: string
  code: string
  description: string
  status: 'OPEN' | 'IN_QUOTATION' | 'APPROVED' | 'IN_PROGRESS' | 'COMPLETED' | 'CANCELLED'
  createdAt: string
  secretaria: { id: string; name: string }
}
```

**Pull-to-refresh pattern:**
```typescript
const [refreshing, setRefreshing] = React.useState(false)
const onRefresh = async () => {
  setRefreshing(true)
  await fetchOrders()
  setRefreshing(false)
}
// <FlatList refreshControl={<RefreshControl refreshing={refreshing} onRefresh={onRefresh} />} />
```
