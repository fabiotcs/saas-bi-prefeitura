## Story
**As a** gestor financeiro,
**I want** acompanhar faturas, status de pagamento e histórico financeiro,
**so that** o controle de custos do contrato seja preciso.

## Acceptance Criteria
1. Filtro por período funcional
2. Totalizadores: faturado, líquido, pago visíveis
3. Fatura com todos os itens de cada pedido
4. Status com cores distintas
5. PDF da fatura visualizável e imprimível
6. Upload de comprovante funcional

## File List
- `src/services/financial.service.ts` — Service com tipos Invoice, InvoiceItem, PaymentHistory, FinancialSummary e funções de API
- `src/app/api/financial/summary/route.ts` — GET com agregação por secretaria, autenticado (MAIN_MANAGER/SECRETARY_MANAGER/AUDIT_VIEWER)
- `src/app/api/financial/invoices/route.ts` — GET (listagem paginada com filtros) + POST (criação, MAIN_MANAGER only) com InvoiceItems via createMany
- `src/app/api/financial/invoices/[id]/route.ts` — GET com secretary, items e payments incluídos
- `src/app/api/financial/invoices/[id]/proof/route.ts` — POST multipart upload para public/uploads/proofs/
- `src/app/(protected)/financial/page.tsx` — Página com 3 cards, filtros, tabela de faturas e gráfico CSS por secretaria
- `src/app/(protected)/financial/invoices/[id]/page.tsx` — Detalhe da fatura com itens, cards, histórico de pagamentos, upload de comprovante e window.print()
- `src/__tests__/financial.test.ts` — Testes vitest cobrindo GET summary, GET/POST invoices com cenários de autorização
