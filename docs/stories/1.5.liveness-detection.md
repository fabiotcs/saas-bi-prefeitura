## Story
**As a** gestor de segurança,
**I want** que o sistema detecte tentativas de fraude com fotos estáticas,
**so that** apenas uma pessoa real e presente possa autenticar.

## Acceptance Criteria
1. Foto estática impressa em papel recusa autenticação com status FAILED ou SUSPICIOUS
2. `fraudAlertLevel` calculado e registrado em todo `BiometricRecord`
3. Sistema bloqueia acesso quando `fraudAlertLevel = HIGH`
4. Alerta visual amarelo exibido no frontend quando `fraudAlertLevel = MEDIUM`
5. `aiEstimatedAge` preenchido pelo provider biométrico quando disponível
6. Liveness detection integrada ao fluxo de `POST /api/auth/biometric-verify` (Story 1.4)

## Tasks / Subtasks
- [x] Implementar análise de liveness no `BiometricProvider` (AC: 1, 2)
  - [x] `assessLivenessFromBuffer`: análise de variância de pixels (fotos planas = variância baixa)
  - [x] `calculateFraudAlertLevel(livenessScore, similarityScore)`: lógica de thresholds
  - [x] Retornar `livenessScore` (0–1) e `fraudAlertLevel` em `BiometricResult`
- [x] Lógica de `fraudAlertLevel` (AC: 2, 3)
  - [x] NONE: livenessScore >= 80 e similarityScore >= 70
  - [x] LOW: livenessScore >= 60 e similarityScore >= 60
  - [x] MEDIUM: livenessScore >= 40 ou similarityScore < 60
  - [x] HIGH: livenessScore < 40 (foto impressa detectada)
- [x] Integrar liveness no endpoint `biometric-verify` (AC: 2, 3, 6)
  - [x] fraudAlertLevel=HIGH: retorna 403 `{ error: 'fraud_detected' }` antes de emitir tokens
  - [x] Registra BiometricRecord com fraudAlertLevel, livenessScore, aiEstimatedAge
- [x] Feedback visual no `<BiometricCapture>` (AC: 4)
  - [x] `fraudAlertLevel = MEDIUM`: banner amarelo "Verificação suspeita detectada"
  - [x] `fraudAlertLevel = HIGH`: banner vermelho "Acesso bloqueado — fraude detectada"
- [x] Testes (AC: 1, 2, 3)
  - [x] Teste unit: livenessScore < 40 → fraudAlertLevel = HIGH
  - [x] Teste unit: fraudAlertLevel = HIGH → endpoint retorna 403
  - [x] Teste unit: BiometricRecord salvo com fraudAlertLevel correto
