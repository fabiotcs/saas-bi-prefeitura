## Story
**As a** gestor de segurança,
**I want** que o sistema detecte tentativas de fraude com fotos estáticas,
**so that** apenas uma pessoa real e presente possa autenticar.

## Acceptance Criteria
1. Foto estática impressa em papel recusa autenticação com status FAILED ou SUSPICIOUS
2. `fraudAlertLevel` calculado e registrado em todo `BiometricRecord`
3. Sistema bloqueia acesso quando `fraudAlertLevel = HIGH`
4. Alerta visual amarelo exibido no frontend quando `fraudAlertLevel = MEDIUM`
5. `aiEstimatedAge` preenchido pelo provider biométrico quando disponível
6. Liveness detection integrada ao fluxo de `POST /api/auth/biometric-verify` (Story 1.4)

## Tasks / Subtasks
- [ ] Implementar análise de liveness no `BiometricProvider` (AC: 1, 2)
  - [ ] Método `assessLiveness(faceImage: Blob): Promise<LivenessResult>`
  - [ ] Técnica: análise de textura (LBP — Local Binary Patterns) para detectar foto plana
  - [ ] OU: challenge de movimento (piscar olhos usando landmarks do face-api.js)
  - [ ] Retornar `livenessScore` (0–100) e `fraudAlertLevel`
- [ ] Lógica de `fraudAlertLevel` (AC: 2, 3)
  - [ ] NONE: livenessScore >= 80 e similarityScore >= 70
  - [ ] LOW: livenessScore >= 60 e similarityScore >= 60
  - [ ] MEDIUM: livenessScore >= 40 ou similarityScore < 60
  - [ ] HIGH: livenessScore < 40 ou movimentos suspeitos detectados
- [ ] Integrar liveness no endpoint `biometric-verify` (AC: 2, 3, 6)
  - [ ] Chamar `assessLiveness` antes de gerar tokens
  - [ ] Se `fraudAlertLevel = HIGH`: retornar 403 com `{ error: 'fraud_detected' }`, NÃO emitir tokens
  - [ ] Registrar `fraudAlertLevel`, `livenessScore`, `aiEstimatedAge` no `BiometricRecord`
- [ ] Feedback visual no `<BiometricCapture>` (AC: 4)
  - [ ] `fraudAlertLevel = MEDIUM`: banner amarelo "Verificação suspeita detectada"
  - [ ] `fraudAlertLevel = HIGH`: banner vermelho "Acesso bloqueado — fraude detectada"
- [ ] Testes (AC: 1, 2, 3)
  - [ ] Teste unit: livenessScore < 40 → fraudAlertLevel = HIGH
  - [ ] Teste unit: fraudAlertLevel = HIGH → endpoint retorna 403
  - [ ] Teste unit: BiometricRecord salvo com fraudAlertLevel correto
