## Story
**As a** gestor da Prefeitura de Araçuaí,
**I want** ver o logo, cores e identidade visual do município no sistema,
**so that** a solução reflita a instituição contratante.

## Acceptance Criteria
1. Layout renderiza sem erros em Chrome, Firefox e Edge
2. Layout responsivo funcional em 375px (mobile) e 1440px (desktop) sem overflow horizontal
3. Logo e cores da Prefeitura de Araçuaí aplicados via BrandConfig
4. Rota `/dashboard` sem token redireciona para `/login` (middleware Next.js)
5. Sidebar responsiva: visível em desktop, colapsa em menu hamburger no mobile
6. Favicon dinâmico carregado da BrandConfig
7. `GET /api/config/brand` e `PATCH /api/config/brand` retornam 200

## Dev Notes
**Sobre o BrandProvider:**
O sistema deve buscar a BrandConfig via `fetchBrandConfig()` no server component do layout, injetar as cores como CSS variables no `<html>` tag e configurar o favicon dinamicamente.

**Breakpoints Tailwind obrigatórios:** `sm:640px`, `md:768px`, `lg:1024px`, `xl:1280px`, `2xl:1440px`

**Estrutura de rotas:**
```
app/
  (auth)/login/          ← público
  (protected)/           ← requer autenticação (middleware)
    dashboard/
    secretaries/
    users/
    orders/
    ... (demais módulos)
```

**Nota:** O middleware deve verificar JWT (não apenas existência do cookie). Usar `jose` para verificar JWT no Edge runtime do Next.js.
