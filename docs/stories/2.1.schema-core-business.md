## Story
**As a** desenvolvedor,
**I want** o schema completo de Secretarias, OS e Auditoria,
**so that** todos os dados do core business sejam persistidos corretamente.

## Acceptance Criteria
1. Migration executa sem erros
2. Código de OS gerado automaticamente e único (ex: OS-2026-0001)
3. Trigger de auditoria ativa para tabelas Order, Secretary, User
