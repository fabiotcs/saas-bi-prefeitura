## Story
**As a** gestor,
**I want** ver todos os detalhes de uma OS, aprovar com 2FA e gerar PDF,
**so that** o processo de aprovação seja seguro e rastreável.

## Acceptance Criteria
1. Timeline visível com todos os passos
2. Notas fiscais listadas na OS
3. 2FA exigido ao aprovar OS
4. PDF gerado com checkboxes digitais

## Tasks / Subtasks
- [x] Página `/orders/:id` — dados gerais, itens, timeline, NFs, entregas, não conformidades
- [x] Componente `<OrderTimeline>` — linha do tempo vertical com data, hora, usuário, foto
- [x] Seção de notas fiscais com link para visualização
- [x] Botão "Aprovar OS" → `<TwoFactorModal>` → `POST /api/orders/:id/approve`
- [x] `POST /api/orders/:id/print` — gera HTML para impressão com checkboxes digitais (fallback: @react-pdf/renderer não instalado)
- [x] Testes: aprovação exige 2FA, PDF gerado

## File List
- `src/app/api/orders/[id]/approve/route.ts` — POST endpoint com validação 2FA e aprovação da OS
- `src/app/api/orders/[id]/print/route.ts` — POST endpoint que retorna HTML formatado para impressão
- `src/components/orders/OrderTimeline.tsx` — componente de linha do tempo vertical
- `src/app/(protected)/orders/[id]/page.tsx` — página de detalhe da OS com aprovação e PDF
- `src/__tests__/order-approval.test.ts` — testes de aprovação com 2FA
