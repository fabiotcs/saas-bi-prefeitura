# Story 2.5: Visão Completa da OS, Aprovação e PDF

## Status
Draft

## Executor Assignment
executor: "@dev"
quality_gate: "@qa"
quality_gate_tools: [typecheck, lint, vitest]

## Story
**As a** gestor,
**I want** ver todos os detalhes de uma OS, aprovar com 2FA e gerar PDF,
**so that** o processo de aprovação seja seguro e rastreável.

## Acceptance Criteria
1. Timeline visível com todos os passos
2. Notas fiscais listadas na OS
3. 2FA exigido ao aprovar OS
4. PDF gerado com checkboxes digitais

## Tasks / Subtasks
- [ ] Página `/orders/:id` — dados gerais, itens, timeline, NFs, entregas, não conformidades
- [ ] Componente `<OrderTimeline>` — linha do tempo vertical com data, hora, usuário, foto
- [ ] Seção de notas fiscais com link para visualização
- [ ] Botão "Aprovar OS" → `<TwoFactorModal>` → `POST /api/orders/:id/approve`
- [ ] `POST /api/orders/:id/print` — gera PDF via @react-pdf/renderer com checkboxes digitais
- [ ] Testes: aprovação exige 2FA, PDF gerado
