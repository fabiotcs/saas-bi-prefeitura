## Story
**As a** gestor municipal,
**I want** gerar PDF binário das Ordens de Serviço com marcador digital de autenticidade (SHA-256) e visualizar estabelecimentos credenciados em mapa interativo,
**so that** documentos sejam autênticos, verificáveis e com layout profissional, e gestores possam localizar fornecedores geograficamente.

## Acceptance Criteria
1. `POST /api/orders/[id]/print` retorna `application/pdf` (binário pdfkit) com `Content-Disposition: attachment; filename="OS-{code}.pdf"`
2. PDF inclui: cabeçalho azul, grid de informações, tabela de itens com totalizador, linha do tempo, bloco de autenticidade com SHA-256, linhas de assinatura, rodapé
3. Bloco "Marcador Digital de Autenticidade" exibe hash SHA-256 do conteúdo da OS, nome/cargo do emissor, timestamp
4. Componente `EstablishmentMap` exibe mapa Leaflet/OpenStreetMap com marcadores coloridos por status (ACTIVE=azul, outros=cinza)
5. Página `/establishments` exibe botão toggle "Ver Mapa / Ocultar Mapa" e integra o mapa via `next/dynamic` (ssr: false)
6. Item 28 PoC: "Emissão de PDF com layout profissional e marcador digital de autenticidade" ✅
7. Item 48 PoC: "Mapa interativo de estabelecimentos credenciados com Leaflet/OpenStreetMap" ✅

## Dev Notes
**pdfkit retorna `Buffer` — converter para `Uint8Array` no `new NextResponse()`:**
```typescript
return new NextResponse(new Uint8Array(pdfBuffer), {
  headers: { 'Content-Type': 'application/pdf' }
})
```

**SHA-256 hash determinístico sobre campos estáveis da OS:**
```typescript
const hashPayload = JSON.stringify({ id, code, status, items: [...] })
const documentHash = crypto.createHash('sha256').update(hashPayload).digest('hex')
```

**Leaflet SSR fix (Next.js):**
- `next/dynamic(() => import(...), { ssr: false })` na página
- `delete (L.Icon.Default.prototype as Record<string, unknown>)._getIconUrl` dentro do `useEffect`
