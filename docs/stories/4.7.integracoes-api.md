## Story
**As a** administrador do sistema,
**I want** um painel de integrações com gerenciamento de API Keys e logs de chamadas,
**so that** sistemas externos possam consultar materiais e pedidos de forma segura.

## Acceptance Criteria
1. GET `/api/integrations/api-keys` lista chaves (ADMIN)
2. POST `/api/integrations/api-keys` cria nova chave (retorna rawKey apenas uma vez)
3. DELETE `/api/integrations/api-keys/[id]` revoga chave
4. GET `/api/integrations/logs` lista ApiCallLog com filtros
5. GET `/api/integrations/stats` retorna IntegrationStats
6. GET `/api/docs` redireciona para Swagger UI (next-swagger-doc ou swagger-ui-express)
7. Painel com status, tempo de resposta médio, taxa de sucesso
